Dimensions & mesh

Elements are the painted cells: total = Nx × Ny. Nodes = (Nx + 1) × (Ny + 1), with a maximum of 1600 nodes. Apply mesh updates the preview; Run simulation and Export model also apply pending changes. Inspect material regions after remeshing. For a 1D reduction along x, set Ny = 1, use full left/right electrodes, and set top/bottom thermal flux to zero. Keep Ly and depth positive: cross-section = Ly × depth.

Planar 2D

The specified depth converts current density to amperes and heat flux to watts. It is constant throughout the domain.

Material library

Properties at 300 K. Each grid cell references one material.

Temperature-dependent transport

ρₑ(T) = [1 + β(T − 300)] / σ₃₀₀   ·   α(T) = α₃₀₀ + α′(T − 300). The solver includes Joule, Seebeck, Peltier and Thomson effects. Preset values are illustrative.

Electrical electrodes

Remaining boundary nodes are electrically insulated.

Equipotential contacts

The source electrode is at 0 V. In current mode, the sink voltage adjusts to deliver the specified total current. Current density is free to vary across an electrode. Electrode ranges run bottom→top on vertical edges, and left→right on horizontal edges.

Thermal boundaries

Flux is total heat flux, including Peltier, positive outward. Zero flux is adiabatic. Convection value is ambient temperature. Fixed-temperature sides meeting at a corner must agree.

Simulation settings

Steady mode uses only the DC biases. Start with a coarse mesh; refine the mesh and time steps to check your result, especially at 3ω.

The numerical model

J = −σ (∇V + α∇T)
∇ · J = 0
q = αTJ − k∇T
ρCp ∂T/∂t = −∇ · q − J · ∇V

Conservative, grid-aligned nodal control volumes; scalar isotropic materials; perfect interfaces. Electrical and thermal systems use matrix-free conjugate gradients. Nonlinear coupling uses Picard iterations; periodic integration uses BDF2.

No contact resistance, electrical capacitance, inductance, radiation, or front/back surface heat loss. The app supports up to 1600 nodes; practical compute time depends strongly on the case.
